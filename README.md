# 🍽️ Potluck Guest List Manager

A simple and intuitive web application that helps you organize potluck events by managing guest lists and automatically assigning dishes to attendees.

![Potluck Guest List Manager](https://img.shields.io/badge/Status-Active-brightgreen) ![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat&logo=html5&logoColor=white) ![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat&logo=css3&logoColor=white) ![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat&logo=javascript&logoColor=black)

## 📋 Features

- **Guest Management**: Add up to 8 guests to your potluck event
- **Automatic Dish Assignment**: Randomly assigns dishes from a predefined list to each guest
- **Real-time Updates**: Live counter showing number of attendees
- **User-friendly Interface**: Clean, responsive design with intuitive controls
- **Input Validation**: Prevents duplicate entries and empty submissions
- **Visual Feedback**: Alert system when guest list reaches capacity

## 📦 Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Asanag10/assign-a-potluck-dish.git
   ```

2. **Navigate to the project directory**:
   ```bash
   cd assign-a-potluck-dish
   ```

3. **Open in your browser**:
   - Simply open `index.html` in your preferred web browser
   - Or use a local server like Live Server extension in VS Code

## 🎯 How to Use

1. **Add Guests**: 
   - Enter a guest's name in the input field
   - Click "Invite" to add them to the list
   - Maximum of 8 guests allowed

2. **Assign Dishes**:
   - Once you've added all your guests, click "Assign dishes!"
   - The app will randomly assign a dish to each guest
   - Each guest gets a unique dish from the available options

3. **View Assignments**:
   - Scroll down to see the complete list of guests and their assigned dishes
   - Perfect for sharing with your potluck group!
